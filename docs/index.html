Download for Mac

Requires macOS 14 Sonoma or later.

Download and unzip

Download the latest version, then double-click the zip file in your Downloads folder.

Move it to Applications

Drag Port Detective into your Applications folder.

Open it the first time

macOS will say it can’t verify the app, because free apps like this one aren’t notarized by Apple. Click Done, open System Settings › Privacy & Security, and click Open Anyway.

Prefer to build it yourself? Get the source code and double-click the installer inside.

Questions

Why does macOS warn me when I first open it?

Apple charges developers $99 a year to notarize apps, which is what removes that warning. Port Detective is free, so it isn’t notarized. You can read the full source code on GitHub, or build the app yourself from it.

Can it test a cable on its own?

No. A cable only reports a speed when there’s a device on the other end. The speed shown is the slowest of the device, the cable, any hubs in between and your Mac’s port. To test a cable, plug a fast drive in through it.

Which Macs does it work on?

Any Mac running macOS 14 Sonoma or later. Charger details are most complete on MacBooks with Apple silicon. Desktop Macs don’t report charger details, but everything else works.

Does it show Thunderbolt speeds?

Thunderbolt and USB4 devices are detected and listed, but macOS doesn’t reliably report their link speed, so they’re labelled “Thunderbolt” rather than given a number.

Is it really free?

Yes. There are no ads, no subscriptions and no paid upgrade. If you’d like to say thanks, you can buy me a coffee, but it’s entirely optional.

How can I support Port Detective?

Buying a coffee helps cover the time that goes into updates. Starring the project on GitHub, reporting bugs and telling friends help just as much, and they’re free.

How do I remove it?

Click the menu bar icon, open Settings and click Quit Port Detective. Then drag the app from your Applications folder to the Trash.
